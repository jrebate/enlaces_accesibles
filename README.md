# Enlaces legibles

Crea tu página de enlaces para la bio, legible y accesible desde el principio, y descárgala como un solo archivo HTML. Todo pasa en el navegador: tus datos y tu foto no se envían a ningún sitio.

Web: https://jrebate.github.io/enlaces_accesibles/

## Qué hace

- Nombre, una frase sobre ti, foto opcional (con descripción) y la lista de enlaces, con detalle opcional en cada uno.
- Ordenar los enlaces con botones de subir y bajar, que funcionan con teclado y lector de pantalla.
- Cinco estilos con contraste de texto de 7:1 o más, incluido uno automático que sigue el modo claro u oscuro del móvil.
- Avisos sobre textos de enlace poco claros («Pincha aquí»), direcciones usadas como texto, emojis al principio, mayúsculas, enlaces repetidos, `http://` y nombres de usuario en lugar de direcciones.
- Completa sola las direcciones: añade `https://`, y convierte correos en `mailto:` y teléfonos en `tel:`.
- La página descargada lleva idioma declarado, encabezado, lista de enlaces dentro de `nav`, botones de 48 px o más, foco de teclado visible y soporte de modo oscuro, movimiento reducido y colores forzados. No lleva JavaScript ni contadores.
- El archivo guarda los datos dentro, así que se puede volver a abrir en la herramienta para editarlo.

## Medición

GoatCounter (jrebate), eventos con prefijo `enlaces-`: `enlaces-descargar`, `enlaces-copiar-codigo`, `enlaces-ejemplo`, `enlaces-anadir`, `enlaces-foto`, `enlaces-abrir`, `enlaces-error-descarga`, `enlaces-pro-me-interesa`, `enlaces-pro-temas`, `enlaces-pro-dominio`, `enlaces-pro-quitar-marca`, `enlaces-pro-estadisticas`, `enlaces-kofi-pro`, `enlaces-kofi-pie`, `enlaces-contacto-email`, `enlaces-ir-carrusel`, `enlaces-ir-centaurux`. Las páginas que se descargan no cuentan nada.

## Técnica

HTML estático sin compilación ni dependencias, con el CSS base de CentaurUX.

Los avisos son orientativos y no certifican la accesibilidad de ninguna página.
